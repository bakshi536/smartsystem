# 🎓 Campus Analytics Dashboard

A data-driven campus intelligence system that simulates student behavioral data, visualizes patterns on an interactive dashboard, and uses Machine Learning to predict key outcomes.

---

## 📁 Project Structure

```
campus-analytics/
│
├── simulate_campus_data.py     # Step 1 — Generate all datasets
├── eda_preprocessing.py        # Step 2 — Clean & engineer features
├── ml_models.py                # Step 3 — Train all ML models
├── streamlit_app.py            # Step 4 — Run the dashboard
├── requirements.txt
│
└── campus_data/
    ├── students_master.csv
    ├── attendance_logs.csv
    ├── wifi_usage.csv
    ├── electricity_consumption.csv
    ├── mess_footfall.csv
    ├── cleaned/                # Generated by eda_preprocessing.py
    └── models/                 # Generated by ml_models.py
```

---

## 🚀 How to Run

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Generate simulated data
```bash
python simulate_campus_data.py
```

### 3. Run EDA & preprocessing
```bash
python eda_preprocessing.py
```

### 4. Train ML models
```bash
python ml_models.py
```

### 5. Launch the dashboard
```bash
streamlit run streamlit_app.py
```

## 📊 Datasets

| Dataset | Rows | Description |
|---|---|---|
| students_master | 500 | Student profiles |
| attendance_logs | ~1,95,000 | Subject-level daily attendance |
| wifi_usage | ~1,02,000 | Per-session WiFi logs |
| electricity_consumption | ~4,900 | Building-level slot-wise usage |
| mess_footfall | ~1,07,000 | Meal-wise entry records |

---

## 🤖 ML Models

| Model | Type | Goal |
|---|---|---|
| Attendance Risk Predictor | Random Forest Classifier | Predict if a student is at risk of being absent |
| Mess Footfall Predictor | Random Forest Regressor | Forecast how many students will attend each meal |
| Food Quantity Estimator | Rule-based + ML | Estimate kg of food required per meal item |
| Electricity Anomaly Detector | Isolation Forest | Flag unusual electricity consumption |
| WiFi Usage Predictor | Random Forest Regressor | Predict tomorrow's WiFi usage per student |
